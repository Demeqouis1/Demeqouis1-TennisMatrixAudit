# Audit Engine

The deterministic engine executes the active version of every metric, verification rule, disagreement family, dangerous-underdog pathway, and stress/removal test for both players.

`calculateCompletion` is the authority for `AUDIT_COMPLETE`. It requires identity, critical dependencies, symmetric P1/P2 metric handling, complete rule/test counts, evidence-family coverage, calibration, and a valid Matrix firewall. Reason codes are machine-readable and retained with human-readable explanations at the API layer.

Green eligibility is a separate deterministic gate. Matrix-derived values never increase effective independent evidence. Matrix removal failure emits `GREEN_LOCKED`.
