============================================================
PART 1 — PROJECT MANDATE
============================================================

BUILD:
TENNIS MATRIX INDEPENDENT VERIFICATION & AUDIT SYSTEM

TARGET:
Production-grade full-stack application built and maintained in Replit, with a Git-backed repository and version-controlled application code, database migrations, schemas, tests, documentation, rule-engine code, PDF templates, source adapters, reconstruction formulas, and configuration.

THIS IS AN AUDIT ENGINE.

IT IS NOT A CHATBOT THAT WRITES AN ANALYSIS AND THEN CLAIMS THAT THE ANALYSIS WAS COMPLETED.

The application must PROVE execution through persisted state.

CORE RULE 1:
THE MATRIX MAY BE COMPARED TO THE AUDIT.
THE MATRIX MAY NOT DETERMINE THE AUDIT.

CORE RULE 2:
PLAYER 1 AND PLAYER 2 MUST ALWAYS BE EVALUATED SYMMETRICALLY.

CORE RULE 3:
NO EXECUTION RECORD = NO COMPLETION.

CORE RULE 4:
AI may perform research, extraction, interpretation, and evidence summarization, but AI MAY NOT decide whether an audit is complete.

Deterministic application logic controls completion.

The system must:

1. Accept Tennis Matrix match-summary PDFs.
2. Parse every matchup.
3. Research Player 1 AND Player 2 independently.
4. Execute the complete Verification Metrics framework.
5. Execute the complete Verification Audit.
6. Execute the complete Disagreement / Trap Audit.
7. Execute the complete Dangerous Underdog Audit.
8. Execute all stress/removal tests.
9. Reconstruct permitted missing metrics.
10. Compare independent audit to Matrix only AFTER independent conclusion is committed.
11. Apply evolving 183 Final Record calibration.
12. Run Final Combination Gate.
13. Assign DOUBLE GREEN / GREEN / YELLOW / RED-PASS / INCOMPLETE.
14. Produce one combined ranked board.
15. Generate downloadable Master Audit PDF.
16. Monitor match results.
17. Grade completed matches.
18. Automatically update calibration ledger and Verified Win Rates.
19. Preserve every historical audit, source snapshot, calibration version, rule version, formula version, and generated report.
